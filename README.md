# Creative Portfolio Lab

A polished collection of three interactive, dependency-free web projects. Every project is responsive, keyboard-friendly, and ready to deploy on GitHub Pages.

## Projects

### 1. Orbit Focus
A calm focus timer with configurable work and break sessions, quick presets, progress tracking, and an ambient visual state.

### 2. Chroma Lab
An accessible color-palette workshop that calculates WCAG contrast ratios, checks text readability, locks favorite colors, and generates new palettes.

### 3. FairShare
A trip-expense splitter that supports multiple travelers, weighted participation, tip calculation, and a clear per-person settlement summary.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.
